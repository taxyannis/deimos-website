# Deimos — Content Doctrine

The governing reference for all site copy. Where any surface disagrees with this
document, this document wins. Update copy to match the doctrine, not the reverse.

## Positioning

Deimos is a **global independent strategic advisory firm**.

## Core homepage hierarchy

**Headline**

> Global Independent Strategic Advisory Firm

**Hero subline**

> Deimos provides independent strategic advice to principals, investors and
> institutions across private capital, strategic transactions and partnerships.

**Thesis line**

> Reducing capital risk through structure, process and execution.

## Quality register

The site should feel closer to **Evercore / PJT / Moelis** quality, with clear
capability language closer to **Rothschild / Houlihan Lokey** where useful.

## What Deimos is not

Deimos is **not** positioned as any of the following:

- a preparation shop
- a broker, finder or introducer
- an investor-matching platform
- a generic consultancy
- a SaaS platform
- a capital-readiness service

## Language system

The main language system is built on:

- **structure**
- **capital strategy**
- **counterparty alignment**
- **execution discipline**

## Terminology

- Use **"Selected Exposure"** or **"Relevant Exposure"** — never "Work."
