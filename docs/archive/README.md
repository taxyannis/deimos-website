# Archived planning documents

These are historical planning, brief, prompt, critique, audit, and QA documents
from earlier phases of the Deimos site build. They are **superseded** and are
kept only for reference/history.

**They do not govern current content.** The single source of truth for
positioning and content is [`src/content/CONTENT_DOCTRINE.md`](../../src/content/CONTENT_DOCTRINE.md).

Several of these files contain **outdated positioning** that contradicts the
current doctrine (e.g. "boutique advisory firm," "preparation," "capital
readiness," "deals that aren't yet investable/bankable/mandate-ready," and
older metric-hedging notes). Do not treat anything here as instructions.
